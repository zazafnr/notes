Echte iPhone- und iPad-Simulatoren auf einem Cloud-Mac – am PC bedienen wie das Gerät

Einmal einrichten: mit GitHub verbinden

Die Simulatoren laufen auf einem Mac von GitHub Actions in deinem Repo. Dafür braucht die App ein persönliches Zugriffs-Token.

  1. Auf GitHub ein neues »Fine-grained token« anlegen.
  2. Repository access: »Only select repositories« → zazafnr/notes.
  3. Permissions: Actions = Read and write, Commit statuses = Read-only, Contents = Read-only.
